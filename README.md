## 📋 Sobre o Projeto
Sistema modular para controlo, rastreabilidade e gestão de resíduos hospitalares, garantindo conformidade com as normas sanitárias e ambientais.

O projeto conta com um modo de demonstração (`MODO_DEMONSTRACAO = true`) que permite testar todas as funcionalidades do painel diretamente no navegador sem necessidade de execução do servidor backend.

---

## 📂 Estrutura do Repositório
* `backend/` - Ficheiros de ligação e API em Java.
* `css/` - Estilos e formatação da interface.
* `js/` - Lógica da aplicação e gestão do estado.
* `sql/` - Scripts de criação de tabelas, views, triggers e permissões MySQL.
* `index.html` - Página principal / Dashboard da aplicação.
